01 / APRESENTAÇÃO

Sobre o jogo

O Último Sinal é um projeto de jogo 2D de terror desenvolvido como parte de uma atividade escolar. A proposta é criar uma experiência com ambientação sombria, exploração e criaturas misteriosas.

O projeto envolve a criação de personagens, animações, cenários e mecânicas de jogo, utilizando a Unity como ferramenta de desenvolvimento.

Esta página reúne informações e registros do processo de criação do jogo.
